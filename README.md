# WorkHub - Dashboard Karyawan

Dashboard karyawan berbasis React + Vite.

## Cara menjalankan

1. Pastikan Node.js sudah terinstall.
2. Buka terminal pada folder project.
3. Jalankan:

```bash
npm install
npm run dev
```

4. Buka alamat localhost yang muncul di terminal.

## Build production

```bash
npm run build
npm run preview
```

## Catatan

Data karyawan dan pengajuan masih berupa data dummy di `src/main.jsx`.
Belum ada database, autentikasi, API, atau backend.
